# Adverbs
There are 3 types of adverbs manner, locational and temporal. 
### Manner
Manner adverbs evolved using this proto construction. Stative Verb suffixed with the power class and the comitative postposition. This overtime became less transparent. 
### Locational
Many place nouns can be turned into locational adverbs by means of locative postpositions. There are 2 basic locational adverbs xxxx "here" and xxxx "there". These often appear with the allative, ablative, and illative postpostions

|          | Standard | Allative        | Ablative        | Illative        |
| -------- | -------- | --------------- | --------------- | --------------- |
| Proximal | "here"   | 3rd ALL "here"  | 3rd ABL "here"  | 3rd ILL "here"  |
| Distal   | "there"  | 3rd ALL "there" | 3rd ABL "there" | 3rd ILL "there" |
For the generic locative sense of "here" or "there" the standard form is use. Something like the allative would also be used for the locative for a standard place noun. These adverbs differ in that they are primarily used for motion or for emphasis.
