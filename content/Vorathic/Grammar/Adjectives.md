# Adjectives
`=this.language` has a group of stative [[Vorathic/Grammar/Verbs]] that perform the function of adjectival predicates. They are intransitive, by default, will take the present morphology. This is the basic method of describing any object. The past/future morphology can be used to indicate past/future state for the adjective being used. 
### Placement
An adjective can be used as a prenominal modifier. Do do so they appear in a [[Vorathic/Grammar/Relative Clauses|relative clause]]. See an example bellow:
_**Note the word forms in this example are not real. They are made up and should be replaced once word forms are finalized**_
```gloss
\gla mumu tamo-tsu tsutsu ka-mu-tsu
\glb fairy [to be strong-DRK] demon attack.PRS-LGT-DRK
\ft The fairy attacks the strong demon
```
### Comparison (X is more Y than Z)
The comparison is done by saying that the Z kneels to the X's Y see and example below.
```gloss
\gla tsutsu mumu-ko he zi-tsu-mu
\glb fairy demon-GEN strength kneel-LGT-DRK
\ft The demon is stronger than the fairy
```
_**Note these word forms are not real, made up for the example**_
