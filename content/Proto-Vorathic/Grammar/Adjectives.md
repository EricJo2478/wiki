[[Proto-Vorathic/index|Proto-Vorathic]] has a group of stative [[Proto-Vorathic/Grammar/Verbs|verbs]] that perform the function of adjectival predicates. They are intransitive, by default, will take the present morphology. This is the basic method of describing any object. The past/future morphology can be used to indicate past/future state for the adjective being used.

### Placement

An adjective can be used as a prenominal modifier. To do so they appear in a [[Proto-Vorathic/Grammar/Relative Clauses|relative clause]]. See an example bellow:
