The [[Vorathic Family/Grave Tongue/index|Grave Tongue]] phonology has a very small vowel inventory. The syllable structure is (C)(C)(C)V(C)(C).  You can find a sound frequency chart below the consonant and vowel tables followed by the sound change charge. The proto for this phonology is the [[Vorathic Family/Vorathic/Phonology|Vorathic Phonology]].

### Sound Changes

| Name                  | Change | Notes                                                            |
| --------------------- | ------ | ---------------------------------------------------------------- |
| Word Initial Ejective |        | stops in the word initial position become ejective               |
| Glottal Stop Loss     |        | loss of the glottal stop between vowels                          |
| Back Coalesence       |        | `ao` becomes `ɔ`, `ou` becomes `u`                               |
| Dipthongization       |        | `au` becomes `aw`, `oa` and `ua` become `wa`, `uo` becomes `wo`, |
| Trill Shift           |        | `ʀ` becomes `r`                                                  |
| Trill Velarization    |        | `r` becomes `s` adjacent to a velar                              |
| Trill Loss            |        | `r` lost adjacent to `ɹ` or `l` and becomes `l` elsewhere        |
