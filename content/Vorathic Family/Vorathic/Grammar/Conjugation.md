[[Vorathic Family/Vorathic/index|Vorathic]] has a very extensive conjugation system. Each [[Vorathic Family/Vorathic/Grammar/Verbs|verb]] agrees in [[Vorathic Family/Vorathic/Grammar/Classes|class]] with its subject (and object if present). Then it further conjugates with voicing and tense. To simply the reference for [[Vorathic Family/Vorathic/index|Vorathic]] conjugation. There are two sets of tables, agreement and TAM tables.

The TAM table can be used on any verb after the apropriate class agreement has been found. Class agreements can be irregular so check the conjugation class of the verb you are conjugating to make sure you find the correct lookup table.

# TAM Table

|                   | Past    | Present | Future  |
| ----------------- | ------- | ------- | ------- |
| Positive          | -nu     | -       | -vo     |
| Negative          | -sonu   | -so     | -sovo   |
| Positive Passive  | -banu   | -ba     | -bavo   |
| Positive Negative | -basonu | -baso   | -basovo |
