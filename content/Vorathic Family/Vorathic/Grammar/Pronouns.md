[[Vorathic Family/Vorathic/index|Vorathic]] pronouns are simple. There is a 1st person and 2nd person which each have a singular and plural form. However over sound changes the first person plural once again sounded the same as the singular. Unfortunately demons are fairly self centered so they didn't care much and never came up with a new 1st person plural.

| Number   | 1st Person | 2nd Person |
| -------- | ---------- | ---------- |
| Singular | [[lo]]     | [[wa]]     |
| Plural   | [[lo]]     | [[wa'o]]   |

The 3rd person held onto the [[Vorathic Family/Vorathic/Grammar/Classes|class]] system and therefor there are 6 forms based on the class. There is no number in 3rd person.

| Class | 3rd Pronoun |
| ----- | ----------- |
| I     | [[wga]]     |
| II    | [[wod]]     |
| III   | [[wur]]     |
| IV    | [[u'o]]     |
| V     | [[uwa]]     |
| VI    | [[wu]]      |
