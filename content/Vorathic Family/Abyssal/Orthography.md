[[Vorathic Family/Abyssal/index|Abyssal]] has a unique orthography used to write it. The font face is called Infernal.ttf. All glyphs are typed as a consonant with an optional vowel following. This orthography is an abugida. The native speakers place the glyphs in following order. When a vowel is typed after a consonant it renders as a diacritic when the font is used. Below is a table of which glyphs correspond with which consonant/vowels in both romanization and IPA:

<span class="infernal">K v r k x ’ N R z f m T p d q g n X t G s P b</span>

| Glyph                           | IPA   | Romanization | Typed |
| ------------------------------- | ----- | ------------ | ----- |
| <span class="infernal">p</span> | p     | p            | p     |
| <span class="infernal">b</span> | b     | b            | b     |
| <span class="infernal">P</span> | p'    | p'           | P     |
| <span class="infernal">t</span> | t/t͡s | t/ts         | t     |
| <span class="infernal">d</span> | d     | d            | d     |
| <span class="infernal">T</span> | t'    | t'           | T     |
| <span class="infernal">k</span> | k     | k            | k     |
| <span class="infernal">g</span> | g     | g            | g     |
| <span class="infernal">K</span> | k'    | k'           | K     |
| <span class="infernal">q</span> | q     | q            | q     |
| <span class="infernal">G</span> | ɢ     | gq           | G     |
| <span class="infernal">'</span> | ʔ     | '            | '     |
| <span class="infernal">f</span> | f     | f            | f     |
| <span class="infernal">v</span> | v     | v            | v     |
| <span class="infernal">s</span> | s     | s            | s     |
| <span class="infernal">z</span> | z     | z            | z     |
| <span class="infernal">R</span> | ʁ/χ   | rh/kh        | R     |
| <span class="infernal">n</span> | n/l   | n/l          | n     |
| <span class="infernal">m</span> | m/w   | m/w          | m     |
| <span class="infernal">N</span> | ŋ     | ng           | N     |
| <span class="infernal">e</span> | ə     | ë            | e     |
| <span class="infernal">a</span> | ɔ     | ö            | a     |
| <span class="infernal">o</span> | ʊ     | u̇           | o     |
_Note: w, l, t͡s, and χ do not have their own glyphs and therefore are merged with others._
