[[Vorathic Family/Abyssal/index|Abyssal]] evolved from [[Vorathic Family/Vorathic/index|Vorathic]] using the following sound changes. The lexurgy code for the sound changes can be found after.

### Sound Changes

| Name                        | Change                                                                                                      |
| --------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Uvularization               | `k` and `g` become `q` and `ɢ` respectively when followed by `ʀ`                                            |
| Uvular Compression          | `o` becomes `ə` adjacent to uvulars                                                                         |
| Bilabial / Coda Laxing      | `o` and `u` become `ʊ` in syllables with codas or adjacent to labials                                       |
| Back Vowel Laxing           | `o` and `u` become `ɔ` and `ʊ` respectively and universally                                                 |
| Low Vowel Centralization    | `a` becomes `ə` universally                                                                                 |
| Rhotic Stopifizes           | `ɹ` becomes `d` next to stops                                                                               |
| Rhotic Fricatifizes         | `ɹ` becomes `z` next to fricatives                                                                          |
| Rhotic Alveolar Loss        | `ɹ` becomes `l` universally                                                                                 |
| Rhotic Trill Loss           | `ʀ` becomes `ʁ` universally                                                                                 |
| Initial Glide Hardening     | `w` becomes `b` word initially                                                                              |
| Approximate Nasal Influence | `w` and `l` become `b` and `n` respectively adjacent to nasals                                              |
| Approximate Collapse        | `w` and `l` become `v` and `d` respectively universally                                                     |
| Voicing Harmony             | All stops, and fricatives change in voicing to match the last stop or fricative in the word (when possible) |
| Degemination                | geminates are lost                                                                                          |
