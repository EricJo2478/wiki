[[Vorathic Family/Abyssal/index|Abyssal]] pronouns use the full set of [[Vorathic Family/Abyssal/Grammar/Cases|cases]]. The number distinction of [[Vorathic Family/Vorathic/index|Vorathic]] was lost due to semantic bleaching. The 1st person is [[dö]] and the 2nd person is [[bë'ö]].

The 3rd person held onto the [[Vorathic Family/Abyssal/Grammar/Classes|class]] system and therefore there are 6 forms based on the class. There is no number in 3rd person.

| Class | 3rd Pronoun |
| ----- | ----------- |
| I     | [[bgë]]     |
| II    | [[böd]]     |
| III   | [[bu̇d]]    |
| IV    | [[u̇'ö]]    |
| V     | [[u̇vë]]    |
| VI    | [[bu̇]]     |
