In [[Vorathic Family/Infernal/index|Infernal]] many words were reunderstood into whichever class made sense. When it was a toss up speakers tended to put things from class I, II, IV, VII into the dark class and things from class III, V and VI into the light class. Below are the [[Vorathic Family/Infernal/Grammar/Nouns|noun]] classes and their proto sources after the [[Vorathic Family/Infernal/index|Infernal]] class collapse.

| Class | Source        |
| ----- | ------------- |
| Dark  | \*Undead -hiɲ |
| Light | \*Fairy -kɨg  |
