[[Vorathic Family/Infernal/index|Infernal]] has a very extensive conjugation system. Each [[Vorathic Family/Infernal/index|index]] agrees in [[Vorathic Family/Infernal/Grammar/Classes|class]] with its subject. Then it further conjugates with voicing and tense. To simplify the reference for [[Vorathic Family/Infernal/index|Infernal]] conjugation, there are two sets of tables, agreement and TAM tables.

The TAM table can be used on any verb after the appropriate class agreement has been found. Class agreements can be irregular so check the conjugation class of the verb you are conjugating to make sure you find the correct row in the lookup table.
_Note: Voicing Harmony is not marked in the tables. Apply voicing harmony as expected._
