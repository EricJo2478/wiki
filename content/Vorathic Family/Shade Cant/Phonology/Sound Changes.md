[[Vorathic Family/Shade Cant/index|Shade Cant]] evolved from [[Vorathic Family/Grave Tongue/index|Grave Tongue]] using the following sound changes. The lexurgy code for the sound changes can be found after.

The [[Vorathic Family/Shade Cant/index|Shade Cant]] phonology is below. The syllable structure is (C)(C)(C)V(C)(C).  You can find a sound frequency chart below the consonant and vowel tables.  For the sound changes that created this phonology from [[Vorathic Family/Grave Tongue/Phonology/index|Grave Tongue]] see [[Vorathic Family/Shade Cant/Phonology/Sound Changes|Sound Changes]].

### Sound Changes

| Name                | Change                       |
| ------------------- | ---------------------------- |
| Ejective Loss       | ejectives become aspirants   |
| Obstruent Devoicing | stops and fricatives devoice |
