[[Vorathic Family/Shade Cant/index|Shade Cant]] has a group of stative [[Vorathic Family/Shade Cant/Grammar/Verbs|verbs]] that perform the function adjectival predicates. They are intransitive, by default, and take the present morphology. This is the basic method of describing any object. The past/future morphology can be used to indicate past/future state for the adjective being used.

### Placement

An adjective can be used as a prenominal modifier. To do so they appear in a [[Vorathic Family/Shade Cant/Grammar/Relative Clauses|relative clause]]. See an example below:

  <tr>
    <td>test</td>
    <td>testa</td>
  </tr>
  <tr>
    <td>test</td>
    <td>test-<span class="sc">A</span></td>
  </tr>
</table>
<p class="gloss-ft">“testing a thing”</p>

### Comparison (X is more Y than Z)

The comparison is done using the ablative postpostition. In essence saying X is Zing from Y. Y takes the postposition. See and example below:
