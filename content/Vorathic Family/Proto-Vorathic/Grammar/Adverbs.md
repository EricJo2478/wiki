There are 3 types of adverbs in [[Vorathic Family/Proto-Vorathic/index|Proto-Vorathic]].

### Manner

Manner adverbs evolved using this construction. Stative [[Vorathic Family/Proto-Vorathic/Grammar/Verbs|Verb]] followed by the word "power" and the comitative postposition.

### Locational

Many place [[Vorathic Family/Proto-Vorathic/Grammar/Nouns]] can be turned into locational adverbs by means of locative postpositions. There are 2 basic locational adverbs xxxx "here" and xxxx "there". These often appear with the allative, ablative, and illative postpostions

|          | Standard | Allative        | Ablative        | Illative        |
| -------- | -------- | --------------- | --------------- | --------------- |
| Proximal | "here"   | 3rd ALL "here"  | 3rd ABL "here"  | 3rd ILL "here"  |
| Distal   | "there"  | 3rd ALL "there" | 3rd ABL "there" | 3rd ILL "there" |
For the generic locative sense of "here" or "there" the standard form is used. Something like the allative would also be used for the locative for a standard place noun. These adverbs differ in that they are primarily used for motion or for emphasis.

### Temporal

Temporal adverbs are constructed using the locational roots. When a root is followed by a locative postpostition it forms a temporal adverb construction. For example "here" followed by the illative postpostion would mean "now". More examples below.

| Root  | Case Post. | Meaning        |
| ----- | ---------- | -------------- |
| here  | illative   | now            |
| there | ablative   | then (future)  |
| face  | ablative   | before (past)  |
| back  | allative   | later (future) |
