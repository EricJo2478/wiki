# Cases
There are 3 cases each pulling double duty (plus the genitive). Where context cannot differentiate additional phrases will be required. Below are the cases and their proto sources. The suffixes only fused after the Vorathic language (right before the first Abyssal sound change.).

| Case                | Suffix  | Proto (Vorathic) | Meaning |
| ------------------- | ------- | ---------------- | ------- |
| Genitive            | -ko     | -ko              | hand    |
| Allative (Adessive) | -məf    | -maf             | mouth   |
| Ablative (Abessive) | -dneŋ   | -daneŋ           | shadow  |
| Illative (Inessive) | -va/-və | -va              | belly   |
*Note: The Ablative lost the schwa due to frequent use. This was irregular and not in lexurgy.*
