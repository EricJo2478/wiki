# Adverbs
There are 3 types of adverbs manner, locational and temporal. 
### Manner
Manner adverbs evolved using this proto construction. Stative Verb suffixed with the power class and the comitative postposition. This overtime became less transparent. 
### Locational
Many place nouns can be turned into locational adverbs by means of locative [[cases]]. There are 2 basic locational adverbs xxxx "here" and xxxx "there". These can appear in the allative, ablative, and illative [[cases]].

|          | Allative              | Ablative              | Illative              |
| -------- | --------------------- | --------------------- | --------------------- |
| Proximal | 3rd p + ALL + "here"  | 3rd p + ABL + "here"  | 3rd p + ILL + "here"  |
| Distal   | 3rd p + ALL + "there" | 3rd p + ABL + "there" | 3rd p + ILL + "there" |
For the generic locative sense of "here" or "there" the allative form is used. These adverbs differ in that they are primarily used for motion or for emphasis.
