# Adverbs
There are 3 types of adverbs manner, locational and temporal. 
### Manner
Manner adverbs evolved using this proto construction. Stative Verb suffixed with the power class and the comitative postposition. This overtime became less transparent. 
### Locational
Many place nouns can be turned into locational adverbs by means of locative [[Abyssal/Grammar/Cases]] from Abyssal. This has become less obvious with the loss of the locative cases in Infernal. There are 2 basic locational adverbs xxxx "here" and xxxx "there". These can appear in the allative, ablative, and illative [[Abyssal/Grammar/Cases|cases]] from Abyssal, however these are not inflections, but fossilized ancient words.

|          | Standard | Allative              | Ablative              | Illative              |
| -------- | -------- | --------------------- | --------------------- | --------------------- |
| Proximal | "here"   | 3rd p + ALL + "here"  | 3rd p + ABL + "here"  | 3rd p + ILL + "here"  |
| Distal   | "there"  | 3rd p + ALL + "there" | 3rd p + ABL + "there" | 3rd p + ILL + "there" |
For the generic locative sense of "here" or "there" the standard form is use. Something like the allative would also be used for the locative for a standard place noun. These adverbs differ in that they are primarily used for motion or for emphasis.
